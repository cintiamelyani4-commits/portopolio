Tentang Saya

Mahasiswi Sistem Informasi • Fakultas Teknik

Nama saya Cintia Melyani. Saat ini saya menjalani studi sebagai mahasiswi Program Studi Sistem Informasi di Fakultas Teknik, Universitas Muhammadiyah Bengkulu.

Ketertarikan saya pada dunia teknologi tumbuh melalui proses belajar membangun halaman web yang rapi, terstruktur, dan mudah digunakan. Saya sudah cukup fasih menggunakan HTML, CSS, dan JavaScript, serta senang mengasah ketelitian visual lewat aktivitas seperti menata ruang dan memasak.
